# 记忆方法：声音、逻辑与图像三条路

## 声音记忆（死记硬背，大量的重复背诵）
- 容量小：7个信息左右
- 短期记忆转化为长期记忆需要重复100-150次
- 网格记忆法
  - 1、首先先多读几遍原文
  - 2、不看原文填空，按照前后文字的提示，尽量去想这个抠掉的空格应该是什么内容。重点敲黑板哦：必须根据前后内容提示开动脑筋去填空。因为，脑力花在哪里，记忆就在哪里。如果如果能填起来，说明你会了。如果填不起来，正好，回头看课文的时候，你一看，原来是这个字啊，然后就会记住了。反复多读几遍。
  - 3、第三步，可以采用模块2。比如前面你抠掉的是“夕阳”的“阳”，变成“夕_”，第二次背诵时你就可以抠“夕阳”的“夕”变成“_阳”。反复多读几遍
## 逻辑记忆（只需记住规律，不记而记，最轻松、最快速）
- 见结构化思维、可视化思维
## 图像记忆（联想记忆法）
- 联想法
  - 一对一联想法
    - 在只有唯一对应关系的两个记忆对象之间进行联想，使双方形成紧密的对应关系。
    - 说明
      - 1、在需要记忆的对象之间寻找“突破口”，在问题和答案之间建立某种联系。
      - 2、联想时能用谐音的首选谐音，谐音困难的，用“加减法”即加字或减字以便于联想，还有夸张（张冠李戴、切取嫁接）
      - 3、联想时，叙述性内容要尽量简短，回忆起来也可以缩短时间。
    - 优缺点
      - 优点：简单灵活，方便快捷，短时间内能记忆大量的短小知识。
      - 缺点：应用范围不够广泛，遇有多层次、复杂的记忆对象时往往力不从心，不过总的来说，用一对一联想法来记忆短小精悍的内容非常奏效。
  - 直接串联联想法
    - 用于记忆5条答案左右的简答题、多选题效果是很好的
    - 优点
      - 1、能一次记忆10项左右的内容（记忆太多内容时容易“掉线”---遗忘），联想起来较简单。
      - 2、联想后，考试中若出现该题，特别是以多选题题型出现时，回忆一下联想，再选择备选答案时，就绝不会出现“好像是又好像不是”的模棱两可的情况；
      - 3、对于记忆名词解释、多选、简答等有若干要点答案的问题有很好的效果；
      - 4、可按前后顺序依次记忆，对于必须按顺序记忆的内容，最适合用此种方法。
    - 缺点
      - 1、一环套一环，所以中间的任何一环都不能中断，即不能遗忘，不然后面的就想不起来了。
      - 2、回忆不方便。有时需要提取的是中间的某一内容，但也得从前往后联想一遍才能找出想要的内容，显得费时。
      - 3、开头第一项内容千万不能忘记，忘记了，后面的各项就“群龙无首”，无从记起了。可偏偏是第一项容易忘记。
    - 诀窍
      - 1、为了能记住第一项内容，可用问题题干与这第一项内容进行联想，以加深印象。
      - 2、在平时学习多项要求的问题时，可打乱原书上的顺序，直接在书本上按便于自己记忆的顺序标出1、2、3等顺序号。
      - 3、两种串联方式：画图串联和故事串联
  - 借助词句联想法
    - 注意
      - 1、“外援”词句的个数要与所需记忆的条款数目相等。
      - 2、所选的词句之间必须是紧密相关的。
      - 3、借助的词句要选用自己所熟悉的
      - 4、联想之前要先划出答案中的关键词
      - 5、有时干脆就用提出问题的题干作为“外援”的词句
      - 6、最好是七项左右的问题，多于7项不太方便选用词句
    - 优点
      - 1、用借助词句联想法能完成多选题、简答题、名词解释、及部分论述题的记忆任务，这些题几乎占了整个卷面分数的50%多。
      - 2、借助词句联想法因为有了“外援”的介入，实际上又变成了一对一联想法和直接串联联想法，记忆难度降低了。
    - 缺点
      - 1、首先要寻找与答案数量对等的词句，这样不太方便。
      - 2、联想能力不强的人，联想起来有些费劲。
      - 3、词句中的字要有具体意象，不是语气词之类。
      - 解决的方法
        - 1、要平时多储备词句
        - 2、想好“外援”后，直接将其写在书上或笔记本上，这样复习时很快就会想起原来的联想
        - 3、要加强联想的训练

  - 要点
    - 1、以一次记忆上百项甚至更多内容
    - 2、应用范围广泛，适用于许多题型的答案要点记忆
    - 3、应用简单，只要你掌握一批编程，然后用一对一联想法去联想就行
    - 4、在应用时，数字每十个编成一组，用时一组一组的用。
    - 5、要过两关：一是要牢靠的掌握一批编程，并且要特别熟练。要做到看到数字，就能不假思索的、脱口而出它的编程的程度。二是联想关，要多联想，先不图快，力求准确，然后再在一“快”字上下功夫。
    - 6、可以剪出100个卡片，在每个卡片的正反面分别写出数字和对应的编程，然后打乱顺序，记得非常熟练的放到一边，然后挨个突破。
    - 7、词句-数字联想法
      - 1、挑选外来语
      - 2、划分数字段落并转换成编程
      - 3、进行联想
      - 4、通过外来语联想起数字编程
      - 5、将编程转换成数字
- 定桩法
  - 1、选择你的宫殿
    - 【1】选择一个你非常熟悉的地方，脑海中轻易地再现这个地方并在其中漫步，比如家里，对细节的再现要很鲜明
    - 【2】试着在你的宫殿里确定一条特别的路线，而不只是再现静止的场景
  - 2、列出明显的特征物
    - 家：办公椅--台式机--冰箱--床--路由器--NAS--布沙发--衣柜--绿色幕布--总开关

    - 茶水间：饮水机--冰柜--微波炉--洗菜池--洗洁精--桌椅--自助售卖机--楼梯--密室-大桌

    - 余娴家：皮沙发--茶桌--打印机--收纳柜--晾衣架--电视机--路由器--冰箱--衣柜--开关

  - 3、把宫殿牢牢印在脑中
  - 4、联系
  - 5、参观你的宫殿
## 实际运用
- 1、填空题、单选题，用一对一联想法解决；
- 2、若涉及数字记忆的填空题、单选题的话就用编码法记忆；
- 3、多选题、名词解释、列举题用直接串联联想法或借助词句联想法；
- 4、简答题、论述题（综合题）可用借助词句联想法或定桩法等记忆。
- 5、实际应用时，按照复述（机械记忆）、加工（图像记忆）、组织（逻辑记忆）三步走，形成稳固可利用的记忆。
