# 备考总纲：先定位短板，再排训练顺序

## 训练顺序按差距排，不按喜好排

备考最常见的浪费是「把时间给擅长且喜欢的模块」。正确顺序是：

1. 先做一次整卷或分模块摸底，得出每个模块的**差距**（不是绝对分数）；
2. 差距最大的模块排最前，占用最多的整块时间；
3. 差距最小但不能交白卷的模块（数量关系）只保简单题；
4. 已经达标的模块只做保持性训练，不重复投入。

## 模块取舍策略

### 核心思路
- 复盘为主，刷题为辅
- 在瓶颈时学习技巧

### 政治理论
- 找最新的高三政治模考题/考研政治选择
- 365时政/学习强国/半月谈
- 和申论一起学习最佳

### 常识
- 1. 找最新的高三地理历史模考题
- 2. 尽量减少时间投入

### 判断推理
- 1. 做考研管综逻辑题（模拟题/真题）
- 2. 图形推理/逻辑填空全面刷题，反复刷错题
- 3. 加强/削弱都是吵架

### 数量关系
- 1. 高中的排列组合/随机事件/概率
- 2. 多用代入法和赋值法解决问题，代入可以找中间数

### 时间规划
1. **碎片时间利用**
    - 午休/卫生间：用粉笔APP完成15题资料分析（限时12分钟）+10题图形推理专项训练
    - 通勤时段：逻辑判断/科学推理/常识/言语理解
2. **晚间强化**（每日2.5小时）
    - 19:30-20:30：分模块突破（数量关系→图形推理→资料分析轮换）
    - 20:40-21:40：申论单一题型精练（重点打磨"问题-影响-对策"结构框架）
    - 21:50-22:00：整理错题本（标注错误类型及解题突破点）

### 专项提升策略
1. **数量关系**
    - 每日精练15题高频题型（工程/排列组合/利润问题），掌握代入排除法和赋值法7
2. **图形推理**
    - 建立"属性→数量→位置→特殊"四步解题流程，每日完成20题规律总结
3. **资料分析**
    - 强化速算技巧（截位直除、百化分），每日4篇限时训练（单篇≤6分钟）
4. **申论稳定**
    - 每日精读1篇时评文章，积累"基层治理""数字经济"等主题规范表达模板1
    - 每周完成2篇大作文（重点打磨对仗式标题和动宾结构分论点）

### 冲刺检测
| 周期 | 核心目标 | 检测标准 |
| :--- | :--- | :--- |
| 第1周 | 建立解题方法论体系 | 资料分析单篇≤6分钟 |
| 第2周 | 全真模考+错题攻坚 | 图形推理正确率≥85% |
| 第3周 | 申论模板定型+时政热点突击 | 大作文35分钟完成框架构建 |
| 第4周 | 适应性训练+心理调整 | 行测整体正确率≥75% |

### 注意事项
1. 建立错题三级分类：A类（必会考点）、B类（冲刺考点）、C类（战略放弃）
2. 行测做题顺序优化：常识（5分钟）→言语（30分钟）→判断（35分钟）→资料（25分钟）→数量（留15分钟）
3. 申论坚持"材料为本"原则，杜绝主观发挥
