# 综合分析题验证顺序

综合分析题通常不需要按 A、B、C、D 固定顺序验证。应按计算成本排序，尽快找到可以确定真假的选项。

## 推荐顺序

1. 直接读取材料即可判断的选项。
2. 涉及单位、时间、范围或概念口径的选项。
3. 只需比较趋势、大小或数量级的选项。
4. 单步计算选项。
5. 需要跨多处找数或连续精算的选项。

## 正误题处理

先在题干上明确圈出“正确”或“错误”。找到符合要求的一项即可停止，不必把其余选项全部算完；但若判断依赖近似值，必须确认误差不会跨过选项边界。

## 不可靠捷径

答案位置分布只能在完全不会且时间耗尽时作为随机兜底，不能替代材料证据。训练时不使用位置规律，以免掩盖知识和计算漏洞。
