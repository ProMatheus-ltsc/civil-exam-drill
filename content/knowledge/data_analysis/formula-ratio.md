# 比重与百分点

比重的本质是**部分 ÷ 整体**。它不难在算，难在**认清谁是整体**——分母错一个指标，整道题就废了。

## 一、一个核心动作：部分 ÷ 整体

```
比重 = 部分量 ÷ 整体量
```

两个常用变形：

| 要求什么 | 算式 |
|---|---|
| 部分量 | 整体量 × 比重 |
| 整体量 | 部分量 ÷ 比重 |

> **认整体的口诀**：整体是题干里那个**能包含其他项的总口径**（如"三次产业投资合计""社会消费品零售总额"）。分项永远做分子。

## 二、分母陷阱：整体常常要自己算

材料常常**不给整体**，只给几个分项。这时：

```
整体 = 各分项之和
```

> 例：材料给"第一、二、三产业投资"，问"第三产业占三次产业合计的比重"——分母必须写成 `120 + 2480 + 5320`，**不能只写后两项**，也不能拿总额里的某一部分凑。

## 三、两期比重变化：问的是"百分点"

题干问"占比**提高 / 下降了几个百分点**"，比的是**两期比重之差**，单位是**百分点**。

不动手也能判方向：

| 比较 | 结论 |
|---|---|
| 部分增速 **>** 整体增速 | 比重**上升** |
| 部分增速 **<** 整体增速 | 比重**下降** |
| 两者相等 | 比重不变 |

> **别和增长率混**：问"百分之几"是增速，问"几个百分点"才是比重差。两者差一个量级，是经典错项来源。

## 四、延伸：贡献率与拉动增长率

同属"部分与整体"这一族，区别只在分母：

- **增长贡献率** = 部分增量 ÷ **整体增量**；
- **拉动增长率** = 部分增量 ÷ **整体基期量**。

> 一个除以整体的"增量"，一个除以整体的"基期量"——落笔前先看清分母是哪一只。

## 五、自检三问

1. **分子分母有没有颠倒？** 部分在上、整体在下。
2. **整体是材料直接给的，还是要自己加总？** 加总时漏项是最常见的错。
3. **问的是"比重"还是"比重的变化"？** 后者要相减，单位是百分点。

> **练习建议**：本关**只写式子、不算结果**。每题落笔前先说一句"分母是谁"——说得出来，式子基本就不会错。
