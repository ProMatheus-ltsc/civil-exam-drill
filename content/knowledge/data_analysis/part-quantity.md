# 部分量

部分量＝整体×占比。这个式子看着简单，考点都在“换口径”上：**整体和占比必须同一年**。求基期的部分量时，整体要换成基期整体、占比要换成基期占比，只换其中一个是最常见的失分点。

## 一、现期部分量

**1、公式**：部分＝整体×比重。

**2、反求整体**：整体＝部分÷比重（比重是敏感分数时用百化分，见《敏感数与百化分》）。

**3、连乘比重**：若 A 占 B 为 a%、B 占 C 为 b%，则 A＝C×a%×b%，可不求中间量 B。

## 二、基期部分量

**1、整体与占比都换成基期**：

- 基期整体＝整体现期÷(1+b)（b 为整体增速）；
- 基期占比＝现期占比−提升的百分点（题干给“比去年提高/降低 X 个百分点”）；
- 基期部分量＝基期整体×基期占比。

**2、若题干直接给了部分的增长率**（a），最快的是按部分自身求基期：基期部分＝部分现期÷(1+a)。

**3、两条路的取舍**：材料分别给“部分增速”与“整体增速+百分点变化”时，两条路都能走，选数字好算的那条；两条路算出结果不一致，多半是百分点用反了方向。

## 三、例题

**例**：2023年某市规上工业增加值占全市GDP的32%，全市GDP为4800亿元，规上工业增加值为多少亿元？
解析：部分＝整体×比重＝4800×32%=1536亿元。

**例**：2023年某市规上工业增加值 1536亿元、同比增长8%，2022年规上工业增加值约为多少亿元？
解析：题干给了部分自身增速，直接求基期：1536÷1.08≈1422亿元。

**例**：2023年某市GDP 4800亿元、同比增长5%；规上工业增加值占比 32%、比上年提高0.6个百分点。2022年规上工业增加值约为多少亿元？
解析：两个因子都换基期——基期GDP＝4800÷1.05≈4571亿元，基期占比＝32%−0.6%=31.4%，基期部分量≈4571×31.4%≈1435亿元。
