# 基期量

基期量就是“去年的量”，两个入口：

- 已知现期和增长率：基期量＝现期÷(1+r)；
- 已知现期和增长量：基期量＝现期−增长量。

判断用哪个入口，看材料给的是增长率还是增长量（“同比增加 X 亿元”给的是增长量，“同比增长 X%”给的是增长率）。四量关系见《增长四量关系》。

## 一、现期÷(1+r) 的三种速算

**1、百化分**：r≈1/n 时，基期量＝现期×n/(n±1)。如 r=12.5%=1/8 时基期＝现期×8/9；减少 8% 时基期＝现期×8/7。

**2、化除为乘（r 很小时）**：r＜5% 且选项差距较大时，现期÷(1+r)≈现期×(1−r)。

- 现期 1200、r=6%：1200÷1.06≈1132；用近似得 1200×0.94=1128，误差约 0.4%，选最接近的选项即可。

**3、截位直除**：选项首位不同只算首位、前两位不同算到前两位（详见《除法估算》）。

## 二、基期量比较与多对象

1、比较两个对象的基期量：先比现期量（量级差异大时直接定胜负），现期接近时再看增长率——增长率越大，基期量越小。

2、多个对象求基期量之和/之差时，逐个求基期再加总，注意统一单位与口径（都是“去年”而不是混着现期）。

## 三、例题

**例**：某市2024年GDP为1240亿元、同比增长12.5%，2023年GDP约为多少亿元？
解析：12.5%=1/8，用百化分：1240×8/9≈1102 亿元（也可直接 1240÷1.125）。

**例**：某省2024年服务业增加值2400亿元、比上年增加300亿元，2023年为多少亿元？
解析：题干给的是增长量，用减法：2400−300=2100 亿元。

**例**：某市2024年财政收入1200亿元、同比增长6%，2023年约为多少亿元？
解析：r＜5% 的边缘情况用化除为乘：1200×(1−6%)=1128；精确算 1200÷1.06≈1132，按选项距离取更接近的值。

**例**：2019年A市财政收入1200亿元（同比增长6%），B市900亿元（同比增长8%），2018年两市财政收入相差约多少亿元？
解析：分别求基期——A 市 1200÷1.06≈1132、B 市 900÷1.08≈833，相差约 299 亿元。（两个对象的基期差见《基期差》。）
