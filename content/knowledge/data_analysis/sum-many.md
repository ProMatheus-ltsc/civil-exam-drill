# 多项求和

“几个分项加总”“三个季度合计”都属这一类。

**3 项是分界线**：3 项以内逐项相加还受得住；**4 项以上就该换算法**（基准数法、配对凑整、分位累加，见《多项连加》——项数一多，中间和与进位都会成倍消耗脑力）。本篇讲 3 项的三种做法。

## 一、配对凑整（最优先）

**1、做法**：扫个位，把能凑成 10 的两项配成一对，配完整十再加剩下的那一项。

**2、示例**：47+63+18——47+63=110，再加 18，合计 128。

**3、要点**：配对只看个位（3 与 7、4 与 6、9 与 1、2 与 8、5 与 5）；配不上的零头最后单独加。个位是 0 的数凑不出整十，直接当整十加数。

## 二、分位相加（高位叠加）

**1、做法**：把各项拆成“整十/整百部分”和“个位零头”，两部分各自求和，再合并进位。

**2、示例**：646+794+120——整十部分 640+790+120=1550，零头 6+4+0=10，合计 1560。

**3、为什么稳**：零头之和一般不到 30，进位只有 1~2，不会在中间某一步丢数。

**4、更规范一点的写法**：把同一位上的数分别相加、逐位进位（个位一列、十位一列、百位一列），就是《多项连加》里的“分位累加”——3 项用起来同样顺手。

## 三、基准数法（几项都挤在同一整十附近）

**1、做法**：取一个整十当基准，把每项写成“基准 ± 差值”，则总量 ＝ 基准×项数 ＋ 差值合计。

**2、示例**：185+166+195——三项都贴着 180，写成 180+5、180−14、180+15，差值合计 6，总量 180×3+6=546。

**3、适用边界**：最大值与最小值相差不超过 50 时最好用；跨度太大就退回配对法。

## 四、尾数法

**1、用法**：选项末位互异时，只算各项个位之和的个位，直接对选项。137+284+59 的个位 7+4+9=20，答案末位为 0。

**2、边界**：题干带“约”字不能用；选项末位相同或相邻（干扰项按 ±10 设计时）也用不上，必须老实算进位。

## 五、例题（均为 3 项）

**例**：不使用计算器，计算 137+284+59。
解析：零头 7+4+9=20（进 2），整十部分 130+280+50=460，合计 480。

**例**：不使用计算器，计算 168+282+642。
解析：个位 8 与 2 凑十 → 168+282=450，再加 642，合计 1092。

**例**：不使用计算器，计算 222+250+220。
解析：三项都贴着 230 → 基准数法：230×3=690，差值 −8、+20、−10 合计 +2，答案 692。

## 六、4 项以上怎么办

项数一多，逐项累加要一直记着越来越大的中间和、还得反复进位，错误率陡增。第四项起改用《多项连加》的三招：**各项挤在同一水平用基准数法、个位能凑十的先配对、没结构的用分位累加**，最后用个位校验回查。
