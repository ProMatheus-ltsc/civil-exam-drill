# 增长量与平均数

这一关的两类问法看着毫不相干，但错法是同一个：**分母（基数）取错了**。

## 一、增长量：绝不能用"现期 × 增速"

题干问"比上年增加（减少）多少"，求的是**增长量**：

```
增长量 = 现期量 × 增长率 ÷ (1 + 增长率)
```

> **为什么不能直接用"现期 × 增速"？**
> 因为增速是**相对基期**算出来的。拿现期去乘，等于把基数放大了一档，结果**系统性偏大**。只有增速极小（不足 1%）时才能勉强近似。

**下降时的写法**：把降幅当负增长率代进去，或直接用：

```
减少量 = 现期量 × 降幅 ÷ (1 − 降幅)
```

> 关键动作：**先把 (1 + r) 里 r 的正负定下来**，再落笔。

## 二、平均数：先问"每份是什么"

```
平均数 = 总量 ÷ 份数
```

它和比重一样是除法，区别在**分母的含义**：

| 类型 | 分母是什么 | 例子 |
|---|---|---|
| **比重** | 一个**整体量** | 出口额 ÷ 进出口总额 |
| **平均数** | **份数**（人、天、家、辆…） | 工资总额 ÷ 人数 |

> 判断方法：**看分母带不带"单位个数"**。带（人 / 天 / 个）就是平均数；不带、只是同单位的另一个总量，就是比重。

## 三、延伸：平均数的增长率

若总量增速为 a、份数增速为 b，求"平均数比去年增长百分之几"：

```
平均数增长率 = (a − b) ÷ (1 + b)
```

> 注意：**分母是 (1 + b)**（份数那一项），不是 (1 + a)；问的也是"百分之几"，不是百分点。

## 四、自检三问

1. **求增长量时，除数是不是 (1 + r)？** 漏掉它就是最典型的错。
2. **r 是正还是负？** 下降题忘带负号，结果会离谱。
3. **这是平均数还是比重？** 看分母是不是"份数"。

> **练习建议**：本关**只写式子、不算结果**。写完先别算，回头确认"分母对不对"——这一关的错，九成都在分母上。
