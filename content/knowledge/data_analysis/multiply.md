# 乘法与平方

先纠正一个常见误区：**资料分析里的乘法，绝大多数不需要算准。**

真题的选项差距通常在 5% 以上，只要能估到「数量级 + 首位有效数字」，就能锁定答案。硬算完整乘积不但浪费时间，还会把自己拖进 25 分钟做不完 20 题的困境。本模块按真题的实际构成分四块来讲：

1. **估算**（主体，约 2/3 题量）——两数相乘时，用「看三位、取两位」把计算量砍到九九表以内（第一节）；
2. **取两位后的两位数相乘**——砍剩的两个两位有效数字怎么快速乘起来（第二节）；
3. **平方**（约 1/5 题量）——增长率的复合、几何面积、方差等场景里出现平方，用「凑整十」一步出结果（第三节）；
4. **精确计算**（少数派，约 1/6 题量）——只在选项差距 <5%、末位被锁死时才需要（第四节）。

至于头同尾合十、基准数法、倍数换算那一类口算技巧，属于通用心算修养，**资料分析里命中率极低**：有效数字法已经把数字预处理成整十整百，剩下的乘法难度本就很小。本模块不为它们安排专项训练——但「认得出就用、认不出走通用路径」的定位，保留在第二节。

## 一、乘法：看三位、取两位

### 1、操作步骤

**第一步**：两个乘数各自保留**前两位有效数字**，第三位作为观察位。
**第二步**：按观察位决定取舍（三种情况）。
**第三步**：把取舍后的两个两位数相乘，得到估算值。

> 有效数字：从一个数左边第一个非 0 数字开始数。如 0.5234 的前三位有效数字是 523；2781.7 的前两位是 27。

### 2、取舍三原则

| 情况 | 规则 | 例 |
|---|---|---|
| 两个观察位都在 **0、1、2** | **全舍**：都舍掉第三位 | 21.03×9811 → 21×98 |
| 两个观察位都在 **8、9** | **全进**：都进位 | 899×12811 → 90×13 |
| 其它一切情况 | **一进一舍**：前两位**较小**的一方四舍五入，**较大**的一方反向变化 | 68.61×428.3 → 68×430 |

**「一进一舍」详解**：先比较两个数的**前两位有效数字**谁小（注意：比的是有效数字，不是数本身的大小）。

- 68.61 的前两位是 68，428.3 的前两位是 42 → **42 更小，它是「小数」**
- 小数 428.3 的第三位是 8（≥5）→ 四舍五入进位 → 430
- 大数 68.61 就**反向**舍位 → 68
- 结果 68×430 = 29240

### 3、例题

**例**：181.9×312.6 = ?
观察位是 1 和 2 → **全舍** → 180×310 = 55800。

**例**：2781.7×1.697 = ?
观察位是 8 和 9 → **全进** → 2800×1.7 = 4760。

**例**：3488×7482 = ?
观察位是 8 和 8 → **全进** → 3500×7500 = 26250000。

**例**：2436×4725 = ?
观察位是 3 和 2 → **一进一舍**。前两位 24 < 47，24 是小数，其观察位 3（<5）舍去 → 2400；47 是大数，反向进位 → 4800。结果 2400×4800 = 11520000。

### 4、误差与风险

估算必然有误差，要判断「这个误差会不会选错」：

| 误差来源 | 大致幅度 | 处理 |
|---|---|---|
| 第三位取舍 | 每个乘数 ±5% 以内 | 选项差距 >5% 时安全 |
| **两数同向取舍**（都进或都舍） | 误差叠加，可达 ±10% | 选项差距小时要警惕 |
| **一进一舍** | 一进一舍相互抵消，误差最小 | 优先用这种取舍 |

**判断口诀**：选项差距 >5% → 放心估；选项差距 <5% → 必须精确计算（见第四节）。

### 5、为什么尾数法在本模块失效

本模块的选项**末位全部一致**（例如四个选项都是 `52000 | 55000 | 58000 | 61000`），这是刻意的设计：

- 选项尾数互异时，只需算个位就能定位答案（尾数法），**估算能力根本没被考到**；
- 选项同尾时，尾数法完全失效，只能真的把数量级和首位估出来——这才会练到该练的东西。

**做题时不要去找尾数线索**，直接走「取值 → 取舍 → 相乘 → 比首位」的流程。

## 二、取两位后的两位数相乘

「看三位、取两位」之后，两个乘数都变成了**两位有效数字**，乘积按难度分三档：

| 形态 | 例子 | 处理 |
|---|---|---|
| 整十 / 整百 × 任意 | 50×13、18×31 | 直接口算 |
| 整十几 × 普通两位数 | 13×48、12×63 | 一次分配律 |
| 两个都不是整十 | 68×43、47×28 | 走下面三条路径 |

前两档没有难度。本节的方法**只为第三档准备**——它是估算题里唯一真的需要"技巧"的地方。

### 1、三条路径

**路径一：凑整十 + 分配律（首选，100% 通用）**

规则：**把个位离整十更近的那个数先凑到整十**，跨的步数越小越省力。写成式子就是 `a × b = a × (整十) ± a × (补数)`。

- 47×28：28 跨 2 步到 30，47 要跨 3 步 → 取 28：47×30 − 47×2 = 1410 − 94 = **1316**
- 68×43：68 跨 2 步到 70，43 跨 3 步到 40 → 取 68：70×43 − 2×43 = 3010 − 86 = **2924**
- 83×76：83 跨 3 步到 80：80×76 + 3×76 = 6080 + 228 = **6308**

心算量固定是「一次整十乘 + 一次一位数乘 + 一次加减」，不记特型、不挑场合，性价比最高。

**路径二：拆因数降维（乘数有好因子时才用）**

把乘数拆成两个一位数，连做两次一位数乘法。

- 47×28：28 = 4×7 → 47×4 = 188，188×7 = **1316**
- 63×24：24 = 4×6 → 63×4 = 252，252×6 = **1512**

**判断**：乘数是 4、6、8、9 这类合数时优先试；遇上 23、47 这类质数就退回路径一。

**路径三：十字相乘（速度上限最高，需专门练）**

不凑整、不拆分，固定三步直接出结果：

1. 个位相乘，取个位、记进位 t1；
2. 交叉相乘相加（十位×个位 + 个位×十位）再加 t1，取十位、记进位 t2；
3. 十位相乘再加 t2，得高位。

- 47×28：7×8 = 56（写 6 进 5）→ 4×8 + 7×2 + 5 = 51（写 1 进 5）→ 4×2 + 5 = 13 → **1316**
- 68×43：8×3 = 24（写 4 进 2）→ 6×3 + 8×4 + 2 = 52（写 2 进 5）→ 6×4 + 5 = 29 → **2924**

练熟后每题 3~4 秒，是通用方法里最快的；但它要单独投入，**不练就别用**——强行套用反而比路径一慢。

> **选哪条**：默认走路径一。只有当乘数明显有好因子（路径二）、或你专门练过十字相乘（路径三）时才换。三条路任选一条走到底，中途换方法才是最亏的。

### 2、特型：认识即可，不必专练

有两类乘法有"一眼出答案"的固定套路：

- **头同尾合十**：十位相同、个位相加等于 10 → 「十位×(十位+1)」接「个位×个位」
  43×47：4×5 = 20 接 3×7 = 21 → **2021**
- **尾同头合十**：个位相同、十位相加等于 10 → 「十位×十位+个位」接「个位×个位」
  27×87：2×8 + 7 = 23 接 7×7 = 49 → **2349**

这两类在取两位后的随机分布里**命中率很低**，所以本模块不安排专项训练。但识别只要 1 秒：认得出来白赚 2 秒，认不出来走路径一也不亏——**不要为了等特型而犹豫**。

### 3、它主要藏在哪

取两位后的两位数相乘很少孤立出现，多藏在下面这些位置——而**其中多数位置都有比"硬乘"更快的路**，先想清楚再动算：

| 出现位置 | 表面形态 | 更快的一条路 |
|---|---|---|
| 求部分量 | 总量 × 占比 | 占比先化成 1/n 再约（《敏感数与百化分》） |
| 求现期量 | A × (1+r) | 别乘，拆成 A + A×r，只算零头 |
| 求增长量 | A × r ÷ (1+r) | 化成 A ÷ (n+1)（《增长量》） |
| 求基期量、比重 | 除法形态 | 走截位直除，不属于乘法（《除法估算》《基期量》） |

真正必须做"两位×两位"的，是这些路线都走完之后剩下的最后一步——**所以它的实际出现频率，比你直觉的低。**

## 三、平方：凑整十展开

平方在资料分析里出现于：**增长率的复合**（(1+r)²）、**几何面积**、**方差计算**。

### 1、贴近整十：展开是一步

`(m±d)² = m² ± 2md + d²`

- 47²（贴近 50，d=3）：2500 − 300 + 9 = **2209**
- 38²（贴近 40，d=2）：1600 − 160 + 4 = **1444**
- 93²（贴近 100，d=7）：10000 − 1400 + 49 = **8649**

**为什么快**：`m²` 是整十整百的平方（直接写），`2md` 是一位数乘整十（心算），`d²` 是九九表内的平方。

### 2、尾数是 5：n(n+1) 接 25

`35² = (3×4) 接 25 = 1225`

- 75² = (7×8) 接 25 = 5625
- 95² = (9×10) 接 25 = 9025

**注意**：这一招只在「选项差距大」时能独立定答案；若选项末位相同，它只能帮你快速拿到一个中间值，仍需确认量级。

### 3、平方的实用场景：复合增长率

资料分析里 (1+r)² 很常见。当 r 较小时：

`(1+r)² = 1 + 2r + r² ≈ 1 + 2r`

- r = 5%：1 + 0.1 + 0.0025 = 1.1025，近似 1.1
- r = 8%：1 + 0.16 + 0.0064 = 1.1664，近似 1.17

**r 越小，r² 越可忽略**（r=5% 时 r² 只有 0.0025，占比不到 0.25%）。这是年均增长率题目的常用近似。

## 四、精确计算（少数派，约占 1/6 题量）

资料分析里需要算全的题不多，但一定会有。符合以下任一条，就必须精确计算：

1. **选项差距 < 5%**（首位相同、第二位接近）；
2. **选项末位相同或末两位相同**——出题人故意锁死尾数，估算无从判断；
3. **题干要求「精确到个位」**。

此时**先别急着硬算**。方法不换——**就是第二节那三条路径**，只是精算的数字常升到三位，先多做一步「把三位拆成两位数」的降维：

- 437×28：28 = 4×7（路径二）→ 437×4 = 1748，1748×7 = 12236
- 312×56：56 = 50 + 6（路径一）→ 312×50 = 15600，312×6 = 1872，合计 17472
- 437×23 = 437×20 + 437×3 = 8740 + 1311 = 10051（路径一）

**判断顺序**：乘数能拆成两个一位数吗？能 → 用路径二降维；不能（23、47 这类质数拆不动）→ 走路径一凑整十。

### 算完用末两位自查

完整乘积算出来后，**看末两位能否在选项里对上**。对不上就说明进位错了，回头检查。这是精确计算唯一的保险。

## 五、怎么练

**1、按题量分配精力：估算七成、平方两成、精算一成。** 你在本模块遇到的大部分题都该"看一眼就估"，只有少数题需要动笔算全——先判断题型，再决定投入多少时间。

**2、估算题限时 15 秒**：读题 3 秒、取舍 5 秒、相乘 5 秒、对选项 2 秒。超过 20 秒说明你在硬算，回到第一节重练。

**3、取舍判断是重点，不是乘法本身。** 估算题的失分几乎都在「取舍选错」，而不是「乘法算错」。练习时把每次取舍的理由写出来（全舍/全进/一进一舍），一周后你会形成条件反射。

**4、精算题先想"能不能拆"，再想"怎么算"**：按第二节的三条路径走，拆成两个一位数通常比重算竖式快。

**5、平方题先把常用平方背熟**：11²~25² 是高频，尤其 12²=144、13²=169、14²=196、15²=225、16²=256、17²=289、18²=324、19²=361。

## 六、例题

**例**：不使用计算器估算 4813×127，下列各选项中最接近实际结果的是？
解析：观察位是 1 和 7，不全在 0~2、也不全在 8~9 → 一进一舍。前两位 48 > 12，12 是小数，其观察位 7（≥5）进位 → 13；48 是大数，反向舍位 → 48。估算 48×13 = 624，再把量级补回来（4813 ≈ 48×100，127 ≈ 13×10）→ 624000。实际 4813×127 = 611251，相差约 2%，首位对得上，可锁定答案。

**例**：不使用计算器，计算 47²。
解析：47 贴近 50，d = 3：(50−3)² = 2500 − 300 + 9 = 2209。

**例**：某地区连续两年增长 8%，则两年后的累计倍数是？
解析：(1+8%)² = 1 + 0.16 + 0.0064 ≈ 1.17。r² 只有 0.0064，选项差距大时可直接用 1+2r 近似。

**例**：不使用计算器，精确计算 437×28。
解析：28 = 4×7，先降维：437×4 = 1748，1748×7 = 12236。若选项锁死末位，再用末两位 36 反查选项。

`备注`：本模块只保留资料分析真题实际使用的方法（有效数字乘法、两位数相乘的降维路径、凑整十平方）。通用口算技巧（基准数法、倍数换算等）不属于资料分析必备，本模块不收录；头同尾合十一类特型只在第二节作「认识即可」说明，不安排专项训练。
