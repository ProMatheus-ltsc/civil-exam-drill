# 基期与增速

「基期与增速」是列式的第一关。材料给的是**现在**（现期）和**变化幅度**（增速），而题目要的往往是**过去**（基期），或者反过来让你**算增速**。

## 一、先判方向：要的是"过去"还是"快慢"

| 题干问法 | 要的量 | 怎么落笔 |
|---|---|---|
| "上年（去年 / 基期）是多少" | **基期量** | 除法 → 除以 (1+r) |
| "增长了百分之几" | **增长率** | 求一个比值 |
| "上年比前年多（少）多少" | 基期量之差 | 先各求基期，再相减 |

> **一句话判方向**：出现"上年""去年""基期"，就是求**基期量**；出现"增长百分之几""增速"，就是求**增长率**。

## 二、两个核心公式

**① 基期量：已知现期 A 与同比增速 r**

```
基期量 = A ÷ (1 + r)
```

- r 为正 → 除以大于 1 的数，结果**小于**现期；
- **r 为负（下降）** → 除以小于 1 的数，结果**大于**现期——别把负号丢了。

**② 增长率：两种给法**

| 已知 | 公式 |
|---|---|
| 现期 A、基期 B | r = (A − B) ÷ B |
| 现期 A、增长量 Δ | r = Δ ÷ (A − Δ) |

> **分母永远是"原来那个"**。第二种要先从现期里减掉增量、把基期还原出来，**不能写成 Δ ÷ A**。

## 三、给了两期增速：间隔增长率

已知相邻两期增长率 r₁、r₂，求两期合计：

```
R = r₁ + r₂ + r₁ × r₂
```

> **不是简单相加**。r₁、r₂ 都很小时（比如 2% 与 3%），乘积项只有万分之几，可以近似忽略；但遇到 20%、30% 这类，乘积项能顶几个百分点，不能丢。

## 四、自检三问

写完式子，回问自己：

1. **是"÷(1+r)"还是"×(1+r)"？** 求过去用除，求未来才用乘——资料分析几乎不让你预测未来。
2. **降幅带负号了吗？** "下降 5.6%" 就是 r = −5.6%，代进去是 ÷(1 − 5.6%)。
3. **分子是"变化量"吗？** 算增长率时，分子只能是"变化了多少"，不能是现期或基期本身。

> **练习建议**：本关**只写式子、不算结果**。每题落笔前先说一句"这题要的是基期还是增速"，判断这一步稳了，列式就几乎不会错。
