# 间隔增长率

间隔增长率=`r1+r2+r1×r2`：若2024年同比增长10%、2025年同比增长20%，则2025年比2023年增长`10%+20%+10%×20%=32%`。两率均为正时结果大于两者之和，一正一负时乘积项为负，连续下降时不能简单相加。注意题目跨越的年份数不等于增长率个数：问2025年比2023年，要合并2024、2025两个同比增速。

## 一、间隔增长率

**1、题型识别**：中间隔一个时期（`一般是隔1年，也可以是一个季度、一个月，只要是隔了一个时期都可以算是间隔`），求增长率。例如有三个时期2022、2023、2024，已知2023与2022相比较的增长率为r\_1，2024与2023比较的增长率为r\_2。求2024与2022相比较的增长率r，这种题型称为间隔增长率。

**2、公式**：r=r\_1+r\_2+r\_1×r\_2

**3、公式推导**：设2022年量为1，知道基期及增长率，根据现期公式（基期+(基期×增长率)）则2023量为1+(1×r\_1)=1+r\_1，2024年量为(1+r\_1)+(1+r\_1)×r\_2=1+r\_1+r\_2+r\_1×r\_2，则2024年与2022年比较的增长率=(现期−基期)/(基期)=(1+r1+r2+r1×r2−1)/(1)=r1+r2 + r1×r2

**4、速算技巧**

- （1）先算加法r\_1+r\_2，排除选项

- （2）如果r\_1和r\_2均小于10%，可忽略乘法。示例：5%+8%+5%×8%≈？由于5%、8%均小于10%，可以忽略r1 × r2，则原式≈5%+8%=13%。

- （3）如果r\_1或r\_2大于10%，其中一个百分化。示例：5%+36%+5%×36%≈？由于36%>10%，r\_1 × r\_2不能忽略。可以将5%化成分数为1/20，然后计算36%/20=1.8%，则原式≈41%+1.8%=42.8%。

**5、题型**：

- （1）直接求间隔增长率。

- （2）已知间隔增长率和其中一个增长率，求另一个增长率。

- （3）间隔基期量。若已知2023年现期量和间隔增长率，则2021年基期量=现期量÷（1+间隔增长率）。

拓展：多期增长率（间隔＞一个时期）

   例如已知2023年、2022年、2021年、2020年共四个年份的增长率关系，即求2023年比2020年的增长率。（`隔两年，考的少，了解即可`）

基本公式推导：

2023年比2022年增长r₁
2022年比2021年增长r₂
2021年比2020年增长r₃
则2023年相对于2020年的增长率r为=（1+r₁）×（1+r₂）×（1+r₃）-1 = r₁+r₂+r₃+r₁×r₃+r₁×r₂+r₂×r₃+r₁×r₂×r₃
速算：若所有增长率绝对值均小于10%，可近似忽略乘积项，再根据选项判断是否需要加回主要乘积项。

特殊情况：中间隔“两年”但只有两个增长率？

   例如：“2023年比2021年增长10%，2021年比2019年增长8%，求2023年比2019年增长多少”。2019年到2023年，你会认为隔了3年，是不是要找4个增长率？
解：但题目给的两个增长率不是年度同比增长率，而是跨两年的总增长率。2022和2020不需要去管它。2023年与2019年之间实际只隔了1个年份（2021年）。则带入公式r₁+r₂+r₁×r₂=10%+8%+10%×8%=18.8%。

**例**：（2017国家）2015年全行业全年生产手表10.7亿只，同比增长3.9%，完成产值约417亿元，同比增长4.3%，增速提高1.9个百分点；生产时钟(含钟心)5.2亿只，同比下降3.7%，完成产值162亿元，同比下降4.7%，降幅扩大1.3个百分点

问：2015年我国钟表全行业生产时钟(含钟心)的产值与2013年相比约( )
   A.上升了11%
   B.下降了11%
   C.上升了8%
   D.下降了8%

解析

   本题问2015与2013年相比，中间隔一个时期。本题是间隔增长率计算问题。
   根据题干2014年我国钟表全行业生产时钟(含钟心)的产值的增长率是-(4.7%-1.3%)=-3.4%，那么两期间隔增长率就是，-4.7%-3.4%+4.7%×3.4%，非常接近-8.1%，结合选项选择D选项。

**例**：（2018国家）2017年1～2月，全国造船完工936万载重吨，同比增长123%；承接新船订单221万载重吨，同比增长133%。2月末，手持船舶订单9207万载重吨，同比下降22.6%，比2016年末下降7.6%

   问：2016年末全国手持船舶订单较同年2月末：
   A.降低16.2%
   B.降低2.2%
   C.增加16.2%
   D.增加2.2%

解析

   方法一（正常做）：现期量2016年末手持船舶订单为9207÷（1-7.6%）万载重吨，基期量2016年2月末手持船舶订单为9207÷（1-22.6%）万载重吨。代入增长率公式：(现期)/(基期)-1，计算步骤略，答案为-16.2%，故正确答案为A。
   方法二（间隔增长率）：材料中给了2月末同比的增长率，即相对于2016年2月末的。并且比2016年末下降7.6%。你会发发现有三个时间点，2017年2月末，2016年末，2016年2月末，刚好构成间隔增长率`2016年2月末____2016年末(r₁)____2017年2月末(-7.6%)`，2017年2月末同比下降22.6%，即-22.6%为间隔增长率，问题是求2016年末增长率（r₁），那么带入公式：-22.6%=r₁+(-7.6%)+r₁×(-7.6%)，则r₁= -22.6%+7.6%+r₁×7.6%= -15%+r₁×7.6%＜-15%，答案为A。
