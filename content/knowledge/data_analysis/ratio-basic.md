# 比重与整体量

比重＝部分÷整体。题目出现“占、其中、比重、占比”就是信号，列式前先核对部分与整体的**时间、单位、统计范围**是否同一口径（尤其“其中”后面的部分与前面整体是不是同一年）。部分、整体、比重三量互求是本考点的基本盘，两期比重的升降与差值见《两期比重差》，基期口径见《基期比重》。

## 一、三量互求

**1、求比重**：比重＝部分÷整体。

**2、求部分**：部分＝整体×比重（详见《部分量》）。

**3、求整体**：整体＝部分÷比重。

**4、速算**：截位直除，选项差距大时只算首位。

## 二、两个比重相减

同一整体下比较两个部分的占比，直接相减就是“高几个百分点”。

**技巧**：若 A 占 B 为 a%、B 占 C 为 b%，则 A 占 C 为 a%×b%——连乘比重比先求整体再算两次除法更快。

**例**：（2022四川）2020年末全国群众文化机构从业人员 185076人，其中高级职称 7075人、中级职称 17969人。2020年全国群众文化机构从业人员中，中高级职称占比约为？
A.8%　B.14%　C.27%　D.38%
解析：部分 7075+17969=25044，整体 185076。选项差距大，截位后为 (7+18)÷185=25÷185，首位商 1，答案 B。

**例**：（2011浙江）2009年全国外出农民工 14533万人。从年龄看，31-40岁占22.3%、41-50岁占11.9%。2009年全国“31-50岁”的外出农民工约为多少人？
A.8000万人　B.5000万人　C.3000万人　D.1000万人
解析：占比 22.3%+11.9%=34.2%，部分＝整体×比重＝14533×34.2%≈15000×(30%+4%)=4500+600=5100万人，答案 B。

**例**：（2018北京）2015年1—11月北京市20个文化创意产业功能区实现收入 7019.8亿元，占全市文化创意产业收入的68.8%。其中，文化科技融合示范功能区收入 3772.5亿元、占功能区总收入的53.7%；文化金融融合功能区收入 436.5亿元、占6.2%。文化科技融合示范功能区占全市文化创意产业收入的比重约比文化金融融合功能区高多少个百分点？
A.69　B.48　C.33　D.25
解析：方法一，先求全市收入 7019.8÷68.8%≈10200亿元，再算 (3772.5−436.5)÷10200=3336÷10200，首位商 3，答案 C。方法二，用连乘比重：68.8%×53.7%−68.8%×6.2%=68.8%×47.5%≈33%，同样得 C。
