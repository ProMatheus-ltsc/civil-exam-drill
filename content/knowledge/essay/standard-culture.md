# 规范词：文化发展

## 高频转换

| 材料信号 | 规范表达 |
|---|---|
| 老手艺无人学习、传承人老龄化 | 文化传承面临人才断层 |
| 只展示符号，不讲文化内涵 | 文化开发表层化 |
| 为迎合市场随意改造传统 | 文化资源过度商业化 |
| 运用短视频讲解传统文化 | 创新文化传播方式 |
| 博物馆、图书馆延长开放 | 完善公共文化服务 |
| 城乡文化场馆差距较大 | 公共文化资源配置不均 |
| 文化活动群众参与度低 | 文化供给与需求脱节 |
| 地方文化与旅游项目结合 | 推动文旅深度融合 |
| 打造有辨识度的地方形象 | 塑造地域文化品牌 |
| 对本土文化缺少认同 | 文化认同感不足 |
| 从传统中提取现代设计元素 | 推动传统文化创新性发展 |
| 文化产品走向海外 | 提升文化传播力和影响力 |
| 文化遗址被破坏后才抢救 | 保护意识和预防机制不足 |
| 建档、修缮并培养传承人 | 完善系统性保护传承机制 |

## 作答提示

文化保护与文化利用不是对立关系，材料若同时强调二者，可概括为“在保护中发展、在发展中传承”。
