# 规范词：思想认识

## 高频转换

| 材料信号 | 规范表达 |
|---|---|
| 面对困难仍坚守岗位、履行职责 | 爱岗敬业、恪尽职守 |
| 主动承担急难任务 | 强化责任担当 |
| 拒绝请托、礼品和特殊照顾 | 坚守原则底线、廉洁自律 |
| 主动接近群众、耐心沟通 | 践行群众路线、增强亲和力 |
| 只追求短期成绩和表面效果 | 急功近利、政绩观偏差 |
| 开会留痕多、实际效果少 | 形式主义、工作流于形式 |
| 只重经济指标，忽视环境代价 | 发展理念存在偏差 |
| 不遵守公共秩序、影响他人 | 公共意识薄弱 |
| 大家怎么做就跟着怎么做 | 存在从众心理 |
| 等待外部帮助，不主动改变 | 内生动力不足 |
| 主动探索新办法 | 增强创新意识 |
| 能自我约束、自食其力 | 自立自强 |
| 对风险规则缺少重视 | 安全意识淡薄 |
| 群众不愿参加公共事务 | 主体意识和参与意识不足 |

## 辨析

“意识不足”用于主观认知，“能力不足”用于不会做，“动力不足”用于不愿持续做，三者不能互换。
