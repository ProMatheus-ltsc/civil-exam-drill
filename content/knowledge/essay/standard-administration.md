# 规范词：行政执法

规范词用于概括材料，不是脱离材料背口号。先判断材料在讲问题、原因还是做法，再选强度匹配的表达。

## 高频转换

| 材料信号 | 规范表达 | 使用提示 |
|---|---|---|
| 通过热线、走访、网络收集意见 | 畅通民意表达渠道 | 强调渠道多元 |
| 多个部门都管，却说不清谁负责 | 权责边界不清 | 若互相推脱可写“推诿扯皮” |
| 多部门共同检查、共享结果 | 推进联合执法 | 强调协同而非重复检查 |
| 不分地区和对象采取同样措施 | 政策执行“一刀切” | 属于问题表述 |
| 根据风险或信用安排检查频次 | 实施分级分类监管 | 可补充“提高监管精准性” |
| 随便什么人都能进入、不加甄别 | 准入门槛偏低 | 可接“完善准入审核” |
| 办事只需一个窗口或一次提交 | 推进一站式办理 | 涉及线上可写“全程网办” |
| 处罚很轻，违法收益更高 | 违法成本偏低 | 常对应“提高处罚震慑力” |
| “睁一只眼、闭一只眼”，民不告官不究 | 执法不严 | 属问题表述，对策为“严格执法” |
| 执法人员说理劝导并帮助整改 | 推行柔性执法 | 不等于放松执法 |
| 强调法律法规要落实到位 | 依法治理 | 可写“提高依法治理能力” |
| 回复群众使用“您好”“谢谢” | 用语礼貌规范 | 属服务细节，不宜拔高 |
| 执法记录仪全程开启 | 规范执法过程 | 强调留痕和监督 |
| 使用数据平台发现违法线索 | 提升执法数字化水平 | 可写“以技术赋能监管” |
| 平台用户行为失序、难以规范处罚 | 平台监管不到位 | 可写“压实平台主体责任” |
| 执法力量派到街镇一线 | 推动执法力量下沉 | 强调基层能力 |
| 公开办理进度和结果 | 提升政务公开透明度 | 需与信息公开材料对应 |
| 应公开的信息查不到、不愿透露 | 信息公开不全面 | 可接“保障群众知情权” |
| 政府拒绝透露应公开信息 | 未尊重群众知情权 | 与信息公开配套使用 |
| 群众反映问题不回避、不遮掩 | 态度诚恳、实事求是 | 强调回应姿态 |
| 群众指出问题后积极解决 | 整改不走过场 | 区别于只表态不行动 |
| 答复群众严格按流程和政策 | 严格依据政策、遵守流程 | 强调规范而非推诿 |
| 上级对下级层层监督考核 | 建立分级监督考核机制 | 对应“层层压实责任” |
| 固定时间不间断核查 | 建立定期考核机制 | 可写“常态化考核” |
| 提前研判风险并准备预案 | 健全风险预警机制 | 不要泛写“加强管理” |
| 车辆爆胎、高空坠物等威胁人身财产安全 | 排查整治安全隐患 | 强调事前预防 |
| 未雨绸缪、提前准备 | 防患未然 | 与风险预警同组 |
| 群众、企业、社会组织共同治理 | 构建多元协同治理格局 | 主体必须在材料中出现 |
| 路面晒粮、沿路摆摊 | 违规占道经营 | 属城市管理问题 |

## 作答模板

问题写法：“权责边界不清，多头管理导致监管力量分散。”对策写法：“厘清部门职责，建立信息共享和联合执法机制。”
