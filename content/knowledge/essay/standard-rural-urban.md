# 规范词：城乡发展

| 把农田变景观、农房变民宿 | 发展新业态、创意农业 |
| 林下种菌、林下养鸡 | 发展林下经济 |
| 利用本地山水、气候和传统技艺 | 发挥资源禀赋优势 |
| 村集体办合作社、统一经营 | 发展集体经济 |
| 散户单干改为抱团统一经营 | 提高组织化程度 |

## 作答提示

乡村材料可按“人、地、钱、产业、治理、公共服务”六个维度归类，避免同一段答案反复写“促进发展”。
