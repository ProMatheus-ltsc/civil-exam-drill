# 规范词：城乡发展

## 高频转换

| 材料信号 | 规范表达 |
|---|---|
| 土地荒置、房屋长期无人使用 | 资源闲置、利用效率不高 |
| 青壮年长期外出，老人儿童留守 | 农村空心化、劳动力外流 |
| 大学生和务工人员返乡创业 | 引导人才回流 |
| 山区缺路、缺水、网络不畅 | 基础设施存在短板 |
| 教育医疗资源城乡差距明显 | 公共服务供给不均衡 |
| 只给资金，没有培养持续能力 | 偏重输血、造血能力不足 |
| 发展本地特色种养和加工 | 推动特色产业发展 |
| 农业只卖原料，附加值低 | 产业链条短、附加值不足 |
| 农业与旅游、文化、电商结合 | 推进产业融合发展 |
| 闲置土地重新投入经营 | 盘活农村资源资产 |
| 培训内容多年不变 | 培训供需脱节、针对性不足 |
| 专家按农户需求开展教学 | 开展精准化技能培训 |
| 引进人才后缺少住房教育保障 | 人才配套服务不完善 |
| 本地就业岗位增加 | 拓宽就近就业渠道 |

## 作答提示

乡村材料可按“人、地、钱、产业、治理、公共服务”六个维度归类，避免同一段答案反复写“促进发展”。
