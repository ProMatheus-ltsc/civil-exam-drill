# 规范词：应急管理

这组词覆盖风险排查、预案演练、响应处置与恢复重建。应急类答案按**事前、事中、事后**三段铺开最稳：事前防（排查、预案、演练、物资），事中快（响应、指挥、联动、信息发布），事后补（重建、追责、复盘）。

## 高频转换

| 材料信号 | 规范表达 |
|---|---|
| 平时不检查、出事才补救 | 重处置轻预防 |
| 提前排查隐患、建立台账 | 健全风险隐患排查机制 |
| 制定了预案但从未演练 | 预案流于形式、演练不足 |
| 定期组织应急演练 | 提升应急处置能力 |
| 突发事件多头指挥、信息混乱 | 应急指挥体系不健全 |
| 部门之间信息不通、各自为战 | 应急联动机制不畅 |
| 物资储备不足、调运不及时 | 应急物资保障能力不足 |
| 预警信息发布滞后 | 预警发布不及时 |
| 用短信、广播提前通知群众 | 拓宽预警信息发布渠道 |
| 群众不懂如何避险 | 公众应急意识和自救能力不足 |
| 灾后只修房子、不总结教训 | 缺乏灾后复盘 |
| 事故后层层追责、无人担责 | 责任追究不到位 |
| 基层没有专职应急人员 | 基层应急力量薄弱 |
| 安全隐患长期存在、无人过问 | 安全监管缺位 |
| 企业为赶工期忽视安全 | 安全生产主体责任不落实 |
| 开展安全知识进社区活动 | 加强应急宣传教育 |

## 作答模板

**问题写法**：“重处置轻预防，预案演练不足，应急联动机制不畅，基层应急力量薄弱。”

**对策写法**：“健全风险隐患排查机制，定期组织应急演练，完善应急联动与物资保障，加强应急宣传教育。”

**别写偏**：应急题最容易只写“加强管理”——按事前、事中、事后三段铺开，每段至少落一条具体动作。
