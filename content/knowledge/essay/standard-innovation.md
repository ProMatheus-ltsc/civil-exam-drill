# 规范词：科技创新

## 高频转换

| 材料信号 | 规范表达 |
|---|---|
| 关键设备和技术长期依赖进口 | 核心技术受制于人 |
| 从模仿转向自行研发 | 提升自主创新能力 |
| 企业显著增加研发费用 | 加大研发投入 |
| 基础研究资金来源主要靠单一主体 | 基础研究投入机制单一 |
| 实验室成果没有进入生产 | 科技成果转化不畅 |
| 研发只看技术，不了解市场 | 技术创新与市场需求脱节 |
| 为科技企业提供孵化和加速服务 | 完善创新创业孵化体系 |
| 用专利获得融资 | 拓宽知识产权融资渠道 |
| 保护原创和发明成果 | 强化知识产权保护 |
| 高端人才住房、教育无保障 | 人才配套服务不完善 |
| 不受地域和编制限制引入专家 | 探索柔性引才机制 |
| 老员工退休后技术无人承接 | 科技人才队伍存在断层 |
| 容忍研究失败并奖励创新 | 营造鼓励创新的社会氛围 |
| 政府建设公共研发平台 | 完善科技创新基础设施 |

## 作答提示

科技材料可按“资金—人才—平台—制度—转化—保护—市场”分类，能有效避免对策重复。
