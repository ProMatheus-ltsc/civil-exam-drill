# Day 36 · 事务文书（五）：语言差异与文种速查表

> **今日目标**：理解不同文体的语言差异、掌握「不必注意行文格式」的处理，用一张文种速查表把学过的公文全部收束成可速查的工具。
>
> **本关通关要求**：客观题答对 ≥4 题（共 5 题），且客观题与自评清单的加权总分 ≥80%。做完下面的实操任务、对照清单逐条自评后再交卷。

## 核心知识点

### 1. 不同文体的语言差异

法定公文语言最为庄重严谨；调研报告语言客观理性；倡议书和宣传材料语言富有感染力；讲话稿语言亲切有力；短评语言犀利精炼。**必须根据不同文体调整语言风格，不能一种语气写到底**——这是事务文书最容易丢分的地方，格式对了但语气错了，阅卷人一眼就能看出你没有「入戏」。

### 2. 「不必注意行文格式」的处理

当题目明确要求「不必注意行文格式」「不必写成文章」「写出内容要点／提纲即可」时，**只需写标题和正文（内容要点），省略称谓和落款**。这是考试中常见的简化要求，务必留意审题——它通常与字数限制一起出现（比如不超过 300 字），题目是在提示你把笔墨留给内容。

### 3. 文种速查表

把公文写作阶段讲过的文种摆在一起，考场上判断文种、定格式看这一张就够。

| 文种 | 行文方向／受众 | 一句话核心特征 | 格式要点 |
|---|---|---|---|
| 通知 | 下行／平行 | 让你做事 | 全格式 |
| 通报 | 下行 | 告诉你一件事的结果（表彰／批评／情况） | 全格式 |
| 通告 | 下行，面向社会公众 | 让所有人知道一个规定 | 全格式 |
| 请示 | 上行 | 请求批准，一文一事 | 全格式 |
| 报告 | 上行／下行 | 汇报工作或发布调查报告 | 全格式 |
| 批复 | 下行 | 答复下级请示，与请示成对 | 全格式 |
| 决定 | 下行 | 对重要事项作出决策和部署 | 全格式 |
| 公告 | 下行，面向社会 | 向社会公布重要事项，级别高于通告 | 全格式 |
| 意见 | 上行／下行 | 对重要问题提出见解和处理办法 | 全格式 |
| 纪要 | 下行 | 记载会议情况和议定事项，只记议定不记发言 | 标题 + 正文 |
| 倡议书 | 面向特定群体 | 号召一起做某事 | 全格式（书面类） |
| 宣传稿 | 面向宣传对象 | 宣传主张、鼓动参与 | 标题 + 称呼（网站、刊物上不写称呼落款） |
| 讲话稿／发言稿 | 会上使用 | 宣传、动员、总结性质的口头文稿 | 标题 + 称谓，无落款 |
| 报道 | 面向公众 | 陈述新闻事实、总结经验 | 标题自拟（消息头可有可无） |
| 建议书 | 面向单位或上级 | 提建设性意见，语气商量 | 全格式 |
| 工作建议 | 视题干而定 | 以提出对策为核心；无呈送对象时等同对策题 | 标题 + 正文（有对象则全格式） |
| 公开信 | 面向有关单位、集体、个人 | 书信体议论文，突出倡议呼告 | 全格式 |
| 调研报告 | 面向机关 | 用事实说话，揭示规律并给建议 | 标题 + 正文 |
| 简报 | 向上级反映情况 | 摘要性文书，反映情况、交流经验 | 标题（+ 编发单位与日期） |
| 摘要 | 面向读者 | 只概括内容，不加评论与解释 | 标题 + 正文 |
| 推荐材料 | 向上级或评审单位 | 用事实呈现值得学习的那个「点」 | 标题 + 正文 |
| 短评 | 报刊 | 观点态度鲜明，内在逻辑要求高 | 标题 + 正文 |
| 编者按 | 附于他人文章之前 | 对作品的解释或引申 | 「编者按：」+ 正文，无标题 |
| 导言 | 著作或展览之前 | 引导、介绍 | 标题 + 正文 |
| 提纲 | 依附其他公文 | 只写纲目要点，不写全文 | 标题 + 正文（视题干与字数要求） |

### 4. 三条线索

文种虽多，但真正要记的只有三条线索：

- **受众是谁**——决定语气：对内、对外、对上级各不同。
- **目的是什么**——决定内容重点：号召、建议、反映、评论各不同。
- **要不要落款**——书面类要，讲话类不要，短文与概括类一般只写标题。

## 今日实操任务

### 任务一：综合文种判断（10 分钟）

回顾公文写作阶段学习的所有文种，对照上面的「文种速查表」做两件事：① 把表里「格式要点」一列遮住，自己默写一遍，再对照检查；② 从速查表里挑出三类最容易混的（提示：通知／通报／通告，建议书／工作建议，报道／短评／编者按），各写一句区分它们的判断依据。

### 任务二：语言风格切换（20 分钟）

同一件事（比如「推进垃圾分类」），分别用「法定公文」「倡议书」「短评」三种文体的语气各写两三句开头，体会语言风格的差异。

### 任务三：速查表查漏（10 分钟）

对照速查表，找出你最容易搞混的 3 个文种，把它们抄到笔记本醒目位置。

## 课后作业

1. 判断文种、定格式的三条线索是什么？
2. 什么时候可以「只写标题和内容要点、省略称谓落款」？
3. 倡议书和通知在语气上有什么不同？
