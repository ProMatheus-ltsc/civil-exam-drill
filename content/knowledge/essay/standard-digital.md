# 规范词：数字政府

这组词覆盖政务服务线上化、数据共享、智慧监管与数字鸿沟。数字类材料的陷阱是**只写技术不写人**——平台、数据、算法之后一定要落到服务对象（企业、群众、老年人），否则答案会显得空。

## 高频转换

| 材料信号 | 规范表达 |
|---|---|
| 一个网站办理多项业务 | 推进政务服务“一网通办” |
| 手机端可查询办理进度 | 提升政务服务便捷度 |
| 材料重复提交、多次跑腿 | 减少重复材料、推进“最多跑一次” |
| 各部门数据不互通 | 打破数据壁垒、推进数据共享 |
| 数据只在本地存储、不敢共享 | 数据开放共享不足 |
| 用大数据分析群众需求 | 提升决策精准化水平 |
| 用平台自动预警异常情况 | 推进智慧监管 |
| 系统操作复杂、老年人不会用 | 存在数字鸿沟 |
| 为老年人保留线下窗口 | 保留传统服务方式、推进适老化改造 |
| 平台上线后无人使用 | 应用推广不到位 |
| 各部门系统重复建设、功能雷同 | 重复建设、资源浪费 |
| 数据泄露、个人信息被滥用 | 数据安全保护不足 |
| 网上办事指南不清、找不到入口 | 服务指引不清晰 |
| 跨省事项需回原籍办理 | 推进跨区域通办 |
| 平台收集意见后限期答复 | 健全线上诉求响应机制 |
| 用算法自动派单、分配任务 | 提升治理智能化水平 |

## 作答模板

**问题写法**：“各部门数据不互通，系统重复建设，存在数字鸿沟，数据安全保护不足。”

**对策写法**：“推进政务服务‘一网通办’，打破数据壁垒，推进适老化改造并保留线下渠道，健全数据安全保护。”

**别写偏**：数字政府不是“上了系统就完事”——材料里出现“老年人不会用”“平台没人用”，答案必须写推广与适老化，只写“建设平台”会漏分。
