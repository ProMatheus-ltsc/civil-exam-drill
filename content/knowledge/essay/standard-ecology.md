# 规范词：生态环境

## 高频转换

| 材料信号 | 规范表达 |
|---|---|
| 农药、化肥、养殖废弃物分散排放 | 农业面源污染 |
| 污染企业迁往监管薄弱地区 | 污染产业转移 |
| 环保指标缺少统一规定 | 环境标准体系不完善 |
| 监测设备无法及时发现污染 | 环境监测能力不足 |
| 对违法排污检查和处罚增多 | 加大环境执法力度 |
| 对企业环保信用分级 | 健全环境信用监管 |
| 对受损山水林田统一治理 | 推进生态系统综合修复 |
| 修复矿区后发展种植产业 | 促进生态修复与产业发展协同 |
| 发展低污染、低能耗产业 | 推动产业绿色转型 |
| 垃圾分类、回收和资源化利用 | 推进废弃物减量化资源化 |
| 群众自发参与环境保护 | 培育公众生态自觉 |
| 政府、企业、居民共同治理 | 构建多元环境治理体系 |

## 辨析

“生态修复”针对已经受损的生态系统，“生态保护”强调预防破坏，“绿色转型”强调生产生活方式变化。
