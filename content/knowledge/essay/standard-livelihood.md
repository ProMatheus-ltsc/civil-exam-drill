# 规范词：社会民生

## 高频转换

| 材料信号 | 规范表达 |
|---|---|
| 岗位要求与求职者技能不匹配 | 结构性就业矛盾突出 |
| 新职业劳动者缺少合同保障 | 新就业形态权益保障不足 |
| 老人吃饭看病出行困难 | 养老服务供给不足 |
| 社区服务项目与居民需求不符 | 服务供需匹配度不高 |
| 优质学校集中在少数区域 | 教育资源配置不均衡 |
| 看病流程复杂、重复检查 | 医疗服务协同不足 |
| 困难群体不知道救助政策 | 政策宣传和主动发现不足 |
| 只发补贴，不提供就业支持 | 帮扶方式较为单一 |
| 社会组织参与社区服务 | 引导社会力量参与治理 |
| 志愿活动临时化、难持续 | 志愿服务长效机制不健全 |
| 老旧小区缺少无障碍设施 | 公共设施适老化不足 |
| 托育机构少且价格高 | 普惠托育供给不足 |
| 邻里交流减少、矛盾增多 | 社区凝聚力弱化 |
| 为特殊群体提供定制服务 | 提升公共服务精准性 |

## 辨析

“覆盖不足”是数量问题，“可及性不足”还可能包括距离、价格、时间和信息门槛。
