# 规范词：社会民生

## 高频转换

| 材料信号 | 规范表达 |
|---|---|
| 岗位要求与求职者技能不匹配 | 结构性就业矛盾突出 |
| 求职者多、岗位少，工作很快被替代 | 就业压力较大 |
| 新职业劳动者缺少合同保障 | 新就业形态权益保障不足 |
| 老人吃饭看病出行困难 | 养老服务供给不足 |
| 子女不赡养老人、疏于陪伴家人 | 家庭责任缺失 |
| 社区服务项目与居民需求不符 | 服务供需匹配度不高 |
| 优质学校集中在少数区域 | 教育资源配置不均衡 |
| 只看升学率、只重实用技能 | 教育功利化 |
| 师资薄弱、课堂质量差 | 提高教育质量 |
| 教室简陋、缺少教学设备 | 提升学校软硬件水平 |
| 开设兴趣班和文化课程，提升居民素养 | 推进素质教育、提升居民素质 |
| 看病流程复杂、重复检查 | 医疗服务协同不足 |
| 长期沉闷压抑、悲观焦躁，情绪无处疏解 | 心理健康服务不足 |
| 困难群体不知道救助政策 | 政策宣传和主动发现不足 |
| 房价、教育、医疗支出高 | 生活成本高、生活压力大 |
| 定期体检、关注居民身体指标 | 关注身体健康 |
| 倡导少油少盐、规律作息 | 倡导健康生活方式 |
| 只发补贴，不提供就业支持 | 帮扶方式较为单一 |
| 社会组织参与社区服务 | 引导社会力量参与治理 |
| 志愿活动临时化、难持续 | 志愿服务长效机制不健全 |
| 老旧小区缺少无障碍设施 | 公共设施适老化不足 |
| 托育机构少且价格高 | 普惠托育供给不足 |
| 邻里交流减少、矛盾增多 | 社区凝聚力弱化 |
| 居民对社区有认同感、愿意参与 | 增强归属感 |
| 组织邻里活动、搭建交流平台 | 促进人际交流 |
| 农闲或下班后无事可做 | 业余生活单调 |
| 社区组织文体活动，居民有去处 | 丰富业余生活 |
| 房前屋后整洁、居住舒适 | 改善人居环境 |
| 服务照顾特殊群体习惯和感受 | 服务人性化 |
| 通过手机、网络随时学习知识 | 拓宽获取知识渠道 |
| 为特殊群体提供定制服务 | 提升公共服务精准性 |

## 辨析

“覆盖不足”是数量问题，“可及性不足”还可能包括距离、价格、时间和信息门槛。
