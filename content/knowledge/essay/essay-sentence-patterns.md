# 申论句式模板：标题、开头、结尾

骨架是用来填空的，不是用来背的。考场上先想清楚这一段要干什么（点题、立论、收束），再挑一条骨架往里填具体内容；反过来先背句子再找内容，写出来一定是空话。

## 标题

### 短句式

+ _____是______的关键/重中之重
+ _____要/应当________
+ ______源于/根在_______
+ 让______成为_______
+ 以______促/助_______

### 对偶式

前后两段结构对称、字数相近，读起来稳当，是最不容易出错的一类。写不好的典型表现是两段字数悬殊、词性不对应——前半是动宾，后半也得是动宾。

### 递进式

+ 完善______职能/制度 助力______
+ 坚持______理念/原则 实现______
+ 加强______建设/监督 避免______

### 并列式

+ 完善________ 构建_________
+ 打造/树立________ 培育_________
+ 坚定________ 破除/反对_________

### 眼球吸引法

**此类题目中规中矩，但有一个吸引眼球的词或词组，例如：“用参与的力量提升文化水位”**

该题目起的中规中矩，是最容易学习的题目类型。也就是说，当我们想不出特别好的词汇时，可以借鉴它的结构，至少能够快速拟定一个不差的题目。可以把重点放在结尾词汇的构造上，把题目起的吸引眼球一点，例如该评论的“文化水位”4个字。

本题目的结构是“用A的力量提升B”。其中“力量”可以视情况替换为“活力”，“提升”也可以改为“倒逼”等词。该结构通用性非常强，无论是正面论述/弘扬还是反面驳斥/批判类的文章都可以使用该结构。

以历年国考真题为例：

2016年是关于政策和公民的关系，那么题目可以起为——用“好政策”的力量提升公民道德水位

2015年是关于“科技的生命化”的，那么题目可以起为——用“生命化”的科技倒逼人类社会进步。

这是最简单安全的起题目的方式，虽然看上去不是那么亮眼，但至少干净漂亮，工整“给力”，看着很舒服。

### 两部三重强调法

“两部”指的是该题目的分为两个部分：
（1）前面部分用**精炼的语言概括**所要描述事物的背景。
（2）后面部分**鲜明地提出**自己的观点。

通过“先概括再发声”的方式强化自己的观点，对自己有足够自信的话，甚至可以直接用设问的方式起题目，然后把所有的结论表述在文章中。

“三重加强”指的是：

①第一重加强：带有**较强动作含义**的词汇，如“推动”、“打造”、“荡涤”等。
②第二重加强：带有“新”、“大”、“全”等字的定语，如“新时代”、“新形势”、“新浪潮”、“大环境”、“全面”等。
③第三重加强：把要描述的关键词加上引号。

**举例：**

**全民参与，凝聚环保“新共识”**
**整合医保，牵起医改“牛鼻子”**
**转型升级提升“中国引力”**
**网购时代，如何安放一碗泡面**

“**如何安放一碗泡面**”也是变相的“三重加强”，“如何”设问，“安放”动作，“一碗”有数量词更加形象。

此类题目的结构极为简单，因为它的核心词就是引号内的词，但却用了三重的加强手法，因此题目显得冲击力极强。为什么说此类取题方法很适合对自己作文实力有自信的考生？因为如果用上这么漂亮的一个题目，然后论述的又很成功的话，会给阅卷老师一个很不错的印象，分数也就相应能提高。

以历年国考真题为例：

2017年国考申论（地市级）：理解“只要我们能静下心来向水学习，我们的智慧和情操就一定能得到提高”作文——把“水之哲”融入新形势下的民族精神。

2016年国考申论（省级）：要求以《论语》中的“不学礼，无以立”为中心议题作文——建设社会主义新时代的“礼仪之邦”。

2016年国考申论（地市级）：思考“好的政策不仅仅是对公民意愿的满足，更是对公民理性乃至德性的滋养”作文——打造全民信仰的“好政策”。

此类取题方法不仅简明，而且可以衍生出很多变化，例如把“强调”的三个元素顺序进行变换。该方法还有一个优点就是不容易跑题。

## 开头

### 递进式

+ 提出问题（背景，名言，事例...）+**分析问题**（原因，危害，重要性...）+**亮明观点**

#### 提出问题

+ 1，不久前，______事件掀起热议/引起广泛关注，折射了________问题。
+ 2，自_________以来，________问题就困扰着我国_________。
+ 3，________会议/领导人提出，要全力解决/重视_______问题。

### 转折式

+ 肯定表述（成绩，优点，进步...)+提出问题+**分析问题**+**亮明观点**

#### 肯定表述

+ 1，_______以来，我国在______领域/行业成绩斐然/取得领先成就，_______突飞猛进。
+ 2，当下，________已进入发展快车道，带来了________的方便/快捷。
+ 3，与______相比，________具有_______的优势/特点，广受人们喜爱。

#### 提出问题

+ 1，但是，当我们站在新的历史发展关口，发现_______问题已经严重干扰了________建设。
+ 2，可总体看来，还存在_________的问题。
+ 3，然而，________的发展并不像它表面那么光鲜，_______问题依然突出。

### 列举式

+ 列举（多用排比）+点明关键（共同点/差异点）+**分析问题**+**亮明观点**

#### 列举

+ 1，从_______到_______，从________到_________，无不展现了__________。
+ 2，_________感叹_________；________说过___________；________也强调___________________。
+ 3，_______坚持________，最终实现了__________；_________未能坚持，以至于__________。

#### 点明关键

+ 1，可见，_________离不开_______的作用。
+ 2，这些人/事物的_________有一个共同点，那就是__________。
+ 3，这些都蕴含着_______的道理/启示。

### 分析问题常见表述

+ ________问题不仅极易造成_______，而且可能引发_________危害，最终造成________后果。
+ 究其根本，________问题源于________，是________的产物/共同作用的结果。
+ _________问题关乎________，关乎______________，关乎___________，____________是__________当务之急。
+ 这些问题如果得不到有效解决，将会导致_______，进而影响_________。
+ 究其原因，在于_______,使得_________陷入_________得恶性循环。
+ _______是_________的核心要求，是________的最高目标，更是________的力量源泉。
+ _______的发展离不开_______，一旦失却，将造成________。

### 亮明观点常用表述

+ 因此，我们必须走________的道路。
+ 解决_______问题，是兴国利民之举。
+ 我们不仅要________，更要_________。
+ 因此，必须正确认识_________,确保________的实现。
+ 唯有坚持_______，才能保证________，继而推动__________顺利实行。
+ 在_________的今天，________，意义深远。

## 结尾

### 六种收尾思路

1. **呼应开头**：把开头提过的场景或问题在结尾回扣一次，形成闭环。
2. **总结收尾**：把三个分论点各压一句，合成一段收束。
3. **拔高主旨、呼应题目**：从具体事项上升到价值层面，末句点题。
4. **引用名人名言收尾**：引完必须跟一句自己的判断，只引不议等于没写。
5. **以小见大后升华**：从个案跳到全局，落到国家、时代、人民。
6. **一句一景的示范收尾**：见下面的范例拆解。

### 一个可以直接学的范例

> “一个国家的教育是什么样子，它的明天就是什么样子。”坦率地说，很少有哪个国家的大学入学考试，像中国的高考一样承载着如此多的期待。“知识的春天”犹在，“发展的春天”已至。面对莘莘学子的殷切期盼，唯有深化高考改革，撬动整个教育链条的良性循环和健康发展，才能让每一个新时代的年轻人，在人生的考试中，牢牢把握梦想的方向。

这个结尾是非常适合申论结尾的样式，极其推荐！下面逐句分析一下：

（1）“一个国家的教育是什么样子，它的明天就是什么样子。

这句“……的样子，明天就是什么样子”的结构非常漂亮，有哲理，而且不落俗套。西瓜在网上查询发现它并非出自某位名人名言，而是出自于2017年3月3日的凤凰新闻。在此建议大家学习这个句子的格式，将其运用在申论大作文的结尾中。例如2017年的“以水为师”就可以这样改写：

“国民的道德素养是什么样子，国家的明天就是什么样子。”（“师水之德”的角度）

“一个国家资源环境利用的样子决定了它未来的样子。”（“保护水资源、治理水污染”的角度）

（2）坦率地说，很少有哪个国家的大学入学考试，像中国的高考一样承载着如此多的期待。

该句式可概括为“坦率地说+很少……像中国一样”，例如：

“坦率地说，很少有哪个国家的国民舆论像中国一样，要求在各行各业都必须成为第一”（“美丽中国”的建设角度）

“坦率地说，很少有哪个国家的经济，像中国一样如此长时间的告诉发展，我们根本没有可以借鉴的成功经验”（“经济健康发展”的角度）

（3）“知识的春天”犹在，“发展的春天”已至。

“犹在+已至”，是非常舒服的递进方法，非常适合讲述正面的事物。例如：

“21世纪是生物的世纪”的口号犹在，“人工智能决定了人类未来”的口号已至。（讲述高新技术发展的角度）

（4）面对莘莘学子的殷切期盼，唯有深化高考改革，撬动整个教育链条的良性循环和健康发展，才能让每一个新时代的年轻人，在人生的考试中，牢牢把握梦想的方向。

该句的结构为“面对殷切期盼+深化+良性循环和健康发展+才能让……（正面叙述）”。还是以“以水为师”为题目， 从“师水之德，提高国民素质”的角度举例：

面对人民群众的殷切期盼，国家应有进一步加强道德建设，以水为师，全面吸收“水德”之美，将“水德”和“民风”融为一体，促使公民素养健康发展，才能让中华民族在以更加昂扬的姿态屹立于世界民族之林。
