# Day 1 · 透析申论考试大纲——搞清楚「考什么」

> **今日目标**：理解申论考试的本质是「能力型考试」而非「知识型考试」，明确大纲要求测查的五大核心能力及其具体内涵，从根本上校准备考方向。
>
> **本关通关要求**：客观题答对 ≥4 题（共 5 题），且客观题与自评清单的加权总分 ≥80%。做完下面的实操任务、对照清单逐条自评后再交卷。

## 核心知识点

### 1. 申论是能力型考试，不是知识型考试

申论自 2000 年纳入公务员考试以来，定位一直没变：为国家机关选拔具备治国理政能力的人才，官方大纲明确写的是测查「能力」。但很多考生读过大纲，备考和作答时仍在用知识型考试的办法——背热点、记模板、套框架。方向错了，分数低是必然的。

### 2. 五大核心能力，根在阅读理解

- **阅读理解能力**：全面把握给定资料的相关内容，准确理解其含义，准确提炼事实所包含的观点，揭示所反映的本质问题。这是所有能力的基础和前提。
- **综合分析能力**：对给定资料的全部或部分内容、观点或问题进行分析归纳，多角度思考，作出合理的推断或评价。
- **提出和解决问题能力**：借助自身实践经验和生活体验，在理解分析材料的基础上发现和界定问题，作出评估或权衡，提出解决问题的方案或措施。
- **贯彻执行能力**：准确理解工作目标和组织意图，遵循依法行政的原则，根据客观实际情况，及时有效地完成任务。
- **文字表达能力**：熟练使用指定语种，运用说明、陈述、议论等方式，准确规范、简明畅达地表述思想观点。

其余四项都建立在阅读理解之上——读不懂材料，分析、对策与表达都无从谈起。

### 3. 三类职位分别考什么

| 职位类别 | 测查能力 |
| --- | --- |
| 中央机关及其省级直属机构综合管理类 | 阅读理解、综合分析、提出和解决问题、文字表达 |
| 市（地）级及以下直属机构综合管理类 | 阅读理解、贯彻执行、解决问题、文字表达 |
| 行政执法类 | 阅读理解、依法办事、公共服务、文字表达 |

三类职位唯一的共性是**阅读理解**与**文字表达**：先读懂材料、再把它说清楚，这是所有岗位的公共底盘。另外两项按岗位性质替换——省级侧重综合分析与政策高度，地市级侧重贯彻执行与具体操作，执法类侧重依法办事与公共服务。所以备考的重心也要跟着职位走。

### 4. 试卷长什么样

申论试卷由**给定资料**、**作答要求**、**注意事项**三部分组成。

- **给定资料**：需要阅读的材料，是完成「作答要求」的基础，内容涉及经济、政治、文化、社会、生态等方面。
- **作答要求**：在阅读材料的基础上需要完成的若干任务，每题都写明分值、字数与作答要求。
- **注意事项**：考试期间需要遵守的事项，印在试卷首页。

以国考为例，注意事项主要交代两件事：**时间怎么分**（如 180 分钟里，阅读给定资料参考 50 分钟、作答参考 130 分钟）和**答题卡怎么用**（一律用现代汉语作答、在指定区域作答、严禁折叠答题卡）。这两类都是**考试当天**才需要的东西，考前翻一遍就行——今天只要记住试卷由这三块构成，不必细究。

### 5. 五类题型与分值分布

| 题型 | 常见分值 | 典型问法 |
| --- | --- | --- |
| 归纳概括题 | 15~20 分 | 根据给定资料 1，概括 L 县在乡村振兴中遇到的主要问题 |
| 综合分析题 | 20~25 分 | 谈谈你对「网红经济既是流量风口，也是治理考场」的理解 |
| 提出对策题 | 15~20 分 | 针对农村电商物流「最后一公里」难题，提出解决措施 |
| 贯彻执行题 | 20~25 分 | 为推广「积分制」乡村治理模式，写一份致村民的倡议书 |
| 申发论述题（大作文） | 40 分 | 围绕材料主题写一篇议论文或策论文 |

归纳概括、综合分析、提出对策俗称**申论小题**；贯彻执行称**公文题**；申发论述称**大作文**。分值最高的始终是大作文，但小题合计占比更大——两者都不能放。

### 6. 申论与高考作文的根本区别

申论写作是「戴着镣铐的舞蹈」：**镣铐**是给定资料和作答要求，**舞蹈**是在此限制下展现分析与表达。

- 高考作文可以天马行空，申论必须紧扣材料；
- 高考作文追求文学意境，申论强调务实可行；
- 高考作文的素材主要来自课外积累，申论的论点论据主要从给定资料中提取。

## 今日实操任务

### 任务一：手抄大纲（30 分钟）

在笔记本上手抄五大能力的官方定义，抄写过程中逐字理解每个关键词的含义。抄完后合上笔记本，尝试凭记忆默写，对照检查。

### 任务二：对比分析（30 分钟）

找一篇申论大作文（**自己写过的，或直接用真题的参考范文**）和一篇高考满分作文，照着下表逐项对照，并在「你的发现」这一列举出具体例子（某一句话、某一个用词都行）。

| 对比维度 | 申论大作文 | 高考满分作文 | 你的发现 |
| --- | --- | --- | --- |
| 素材来源 | 来自给定材料 | 来自课外积累 | |
| 立意方式 | 紧扣材料主旨 | 自由发挥 | |
| 语言风格 | 务实、可操作 | 重文学意境 | |
| 角色定位 | 公务员视角 | 学生视角 | |
| 论据类型 | 材料中的事实 | 名人名言为主 | |

### 任务三：自我诊断（20 分钟）

回顾自己过去的申论作答经历（如果没有，可以先做一套真题的大作文），照下表逐条打勾，并在最后一列写下你的具体表现。

| # | 常见误区 | 我有吗 | 具体表现 |
| --- | --- | --- | --- |
| 1 | 不认真审题，看完题目就匆匆下笔 | ☐ | |
| 2 | 脱离给定材料，自由发挥 | ☐ | |
| 3 | 套用事先准备好的模板 | ☐ | |
| 4 | 把大作文写成「问题一二三、原因一二三、对策一二三」的论述题 | ☐ | |

打完勾的这张表，就是你接下来 38 关要逐一解决的问题清单。
