# 规范词：政府管理

## 高频转换

| 材料信号 | 规范表达 |
|---|---|
| 决策前开展调查和专家论证 | 提升决策科学化水平 |
| 邀请群众讨论公共事项 | 推进民主决策 |
| 政策出台后频繁变化 | 政策稳定性和连续性不足 |
| 上级安排到基层层层加码 | 基层负担较重 |
| 表格报送重复、检查过多 | 存在重复考核、多头报送 |
| 基层人员少、任务多 | 基层治理力量不足 |
| 工作拖延、部门响应缓慢 | 行政效能不高 |
| 通过一个平台办理多项业务 | 推进政务服务集成化 |
| 数据只能在单个部门使用 | 信息壁垒尚未打通 |
| 建立群众评价和反馈机制 | 完善社会监督机制 |
| 发现问题后跟踪整改 | 推动监督闭环管理 |
| 以试点验证后逐步推广 | 坚持试点先行、稳步推广 |
| 根据区域差异制定措施 | 坚持因地制宜、分类施策 |
| 干部缺乏专业知识 | 专业化履职能力不足 |

## 作答提示

对政府工作评价应落到“决策、执行、监督、反馈”具体环节，避免只写“政府不作为”。
