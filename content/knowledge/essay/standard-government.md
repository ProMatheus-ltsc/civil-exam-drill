# 规范词：政府管理

这组词覆盖决策、制度供给、基层治理、干部能力与服务效能。写对策时按「谁来干、干什么、怎么保障」排列：先落主体（政府、职能部门、基层组织），再落动作，最后补机制（考核、监督、常态化）。

## 高频转换

| 材料信号 | 规范表达 |
|---|---|
| 决策前开展调查和专家论证 | 提升决策科学化水平 |
| 情况没摸清就拍板、拍脑袋决策 | 调查研究不深入、决策脱离实际 |
| 邀请群众讨论公共事项 | 推进民主决策 |
| 只强调一方、忽视另一方 | 缺乏统筹兼顾 |
| 政策出台后频繁变化 | 政策稳定性和连续性不足 |
| 法规政策不健全、缺少配套细则 | 健全法规政策体系 |
| 法规很多但解决不了实际问题 | 制定有针对性的法律法规 |
| 法规宣传声势大、落实无声 | 法规落实不到位 |
| 上级安排到基层层层加码 | 基层负担较重 |
| 表格报送重复、检查过多 | 存在重复考核、多头报送 |
| 基层人员少、任务多 | 基层治理力量不足 |

| 政策文件层层转发、实际落地少 | 政策落实不到位 |

| 工作拖延、部门响应缓慢 | 行政效能不高 |
| 群众诉求第一时间受理、限时回复 | 提升响应及时性 |
| 通过一个平台办理多项业务 | 推进政务服务集成化 |
| 政府部门坐等群众上门 | 从被动服务转向主动服务 |

| 不受上班时间限制、散步途中可办 | 办理业务时间灵活 |

| 各下属部门各花各的钱 | 资金使用缺乏统筹 |

| 人力物资调整后可节省一部分 | 提高资源利用率 |
| 政府承诺不兑现、出尔反尔 | 政府公信力受损 |
| 建立群众评价和反馈机制 | 完善社会监督机制 |
| 政府加强与企业、社会组织、志愿者合作 | 政府与民间组织协作 |
| 违法行为突破多个监管关口 | 监管不力 |
| 发现问题后跟踪整改 | 推动监督闭环管理 |

| 重建设、轻管理 | 重建轻管 |

| 管理手段由单一转向多种途径 | 创新管理模式 |

## 作答模板

**问题写法**：“调查研究不深入、决策脱离实际，政策执行走样，基层治理力量不足。”

**对策写法**：“提升决策科学化水平，健全常态化治理机制，压实领导责任，推动监督闭环管理。”

**别写空**：对政府工作的评价要落到“决策、执行、监督、反馈”的具体环节，避免只写“政府不作为”。
